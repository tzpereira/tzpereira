## Selected projects

### ⚙️ [Workflow Execution Engine](https://github.com/thettteus/workflow-execution-engine)

*Reliable execution for AI-assisted workflows.*

An open-source Go runtime for running AI and engineering workflows as explicit, versioned, and auditable systems.

I built and validated a 21-step engineering workflow combining **7 model workers and 14 deterministic steps**. The engine owns retries, branching, replay, schema-enforced outputs, context policies, execution budgets, artifacts, and observability instead of delegating control flow to the model.

It ships as a single static Go binary.

`Go · AI Workflows · JSON Schema · Observability · Execution Engine`

### ⛰ [Plan Patagonia](https://planpatagonia.com)

*Zero-to-one travel product for Patagonia.*

I co-founded and build the product across product direction, architecture, frontend, backend, infrastructure, and AI integrations.

The core site is live. The adaptive itinerary layer is currently in development, using weather, reservation, and transportation data, while destination assets are being curated with our local co-founder.

`TypeScript · Next.js · React · PostgreSQL · Prisma · Docker · S3 · Cloudflare · Claude API`

### 🔧 Kafka Go SDK
